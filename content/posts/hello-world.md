This is a starter post to show the front matter PaperMod expects.

Write your posts in plain Markdown. A new file under `content/posts/` becomes
a new post — no build step, no components, just Markdown and this front matter
block at the top.

## Front matter fields

- `title` — shown as the post heading and in the post list
- `date` — controls ordering and the displayed date
- `draft` — set to `true` to keep a post out of the published build
- `tags` — shown under the post and used to build the `/tags/` pages
- `summary` — optional; used for the post-list excerpt if set

Delete this file once you have real content.
